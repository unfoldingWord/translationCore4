Importar um projeto do translationCore 3

Traga o trabalho do translationCore 3 para o tC4 como um novo projeto, a partir dos arquivos zip de projeto que o translationCore 3 exportou.

Para começar um projeto a partir de arquivos USFM ou de um Scripture Burrito, use Nova Bíblia. Veja Criar um projeto da Bíblia.

Cada importação cria um novo projeto. Nada neste computador muda até você clicar em Importar como uma nova Bíblia.

Passos

  1. No Início, clique em + Adicionar um projeto e depois em Importar um projeto (1).
  1. Escolha Projeto do translationCore 3 (1). Aqui, Arquivos USFM e Scripture Burrito aparecem em cinza com Chega com seu importador. Comece esses a partir de Nova Bíblia.
  1. Solte seus arquivos na área indicada ou clique nela para escolhê-los. Remova um arquivo errado com o ✕ dele.
  2. Clique em Revisar arquivos →.
  3. Leia a revisão. Um ponto verde quer dizer que está tudo bem. Um ponto laranja quer dizer que você precisa agir.
  4. Escolha Consultar no Door43 (precisa de internet) ou Usar versões instaladas (1).
  1. Confira o Nome da Bíblia e o Código do idioma e mude-os, se necessário.
  2. Clique em Importar como uma nova Bíblia. O Início mostra "{name} foi importado", e o novo cartão tem a etiqueta Importado.

Para cancelar, clique em Cancelar ou no ✕. Nada é criado.

Se o botão de importar continuar cinza

  • O nome já está em uso. Digite outro nome para a Bíblia.
  • Um arquivo está danificado. Uma caixa vermelha "Este arquivo não pode ser importado" mostra o motivo. Nada pode ser importado desse arquivo. Veja Mensagens que protegem seu projeto.

Bom saber

  • Os links de Palavras de Tradução (Translation Words Links) ficam fixados em um lançamento _twl (escolhido pela data ao consultar no Door43). Os idiomas sem um repositório de links usam os links em inglês que vêm com o aplicativo.
  • Todos os zips do translationCore 3 de uma mesma importação devem ser do mesmo idioma.
  • A mensagem "foi importado" fica no Início até você fechá-la com o ✕ dela ou reiniciar o tC4.
  • Para adicionar um livro a um projeto que você já tem, use Adicionar um livro › Adicionar livros de arquivos USFM.
