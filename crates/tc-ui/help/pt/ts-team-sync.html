Trabalhar em equipe em vários computadores

Compartilhe um projeto no Door43; depois, cada colega de equipe o abre a partir do Door43 e usa Sincronizar com o Door43 para trocar trabalho.

Quando um projeto da Bíblia ou de Open Bible Stories está no Door43, cada colega de equipe pode trabalhar no próprio computador e trocar alterações com Sincronizar com o Door43.

Começar a compartilhar (dono do projeto)

  1. Na tela Início, selecione Compartilhar no Door43 no cartão do projeto e siga os passos. Veja Compartilhar no Door43.
  2. No Door43, dê a cada colega de equipe acesso de escrita ao repositório. Sem isso, os colegas não conseguem sincronizar.
  3. Agora o cartão diz No Door43 e Compartilhado em o repositório, e o botão dele muda para Sincronizar com o Door43.

Entrar em um projeto (colega de equipe)

  1. Selecione + Adicionar um projeto e depois Abrir um projeto do Door43.
  2. Digite owner/repository, ou cole o link do repositório, e clique em Abrir projeto. Um repositório privado abre depois que você entra no Door43.
  3. Se a internet estiver desligada, o tC4 pergunta antes. Clique em Ativar internet; Agora não não traz nada.

O projeto mantém o nome que a equipe deu a ele; o tC4 não pede um nome. O tC4 verifica cada arquivo antes de adicionar o projeto.

Um projeto usa versões exatas dos seus textos-fonte e ajudas. Se algumas delas não estiverem no seu computador, o tC4 as baixa primeiro, e a janela informa o nome de cada uma, por exemplo Baixando en_tn v91, que este projeto usa. Versões restantes depois desta: 8. Uma barra abaixo mostra o andamento dessa versão. Clique em Cancelar para parar: a janela diz A abertura foi cancelada. Nenhum projeto foi adicionado a este computador.

  • Se o projeto já estiver neste computador, a janela diz Você já tem este projeto neste computador. Um projeto tem uma cópia em cada computador. Clique em Abrir o seu.
  • Se o Door43 não tiver uma versão que o projeto usa, ou se ela não puder ser baixada, a janela diz Não é possível abrir este projeto. e informa a versão, por exemplo O Door43 não tem en_ult v91, que este projeto usa. Nenhum projeto é adicionado. Clique em Pedir ajuda se isso continuar acontecendo.

Sincronizar

Selecione Sincronizar com o Door43 no cartão do projeto. O resultado diz quantas alterações vieram dos colegas e quantos conflitos mantiveram a versão mais recente. Se um colega alinhou o mesmo versículo depois de você, o resultado informa qual, por exemplo Tito 1:1: o alinhamento de Ana substituiu o seu. Suas ligações nesse versículo voltam para o banco de palavras. Abra o versículo em Alinhar para conferir. Nada é mesclado automaticamente.

Se a internet estiver desligada, o tC4 pergunta antes. Agora não não envia nada. Se você não estiver conectado, o tC4 pede que você entre no Door43.

Versões que o projeto usa

Um colega pode ter passado o projeto para uma versão mais nova de um texto-fonte ou de uma ajuda, ou este computador pode não ter uma das versões que o projeto usa. Quando a sincronização termina, o tC4 baixa cada versão que falta neste computador, sem perguntar. Durante o download, o cartão do projeto diz, por exemplo, Baixando es-419_twl v18, que este projeto usa. Versões restantes depois desta: 4. Uma barra e Cancelar o download ficam ao lado.

  • A sincronização vale mesmo que você cancele o download ou que uma versão não possa ser baixada. Suas alterações foram enviadas, e as alterações dos colegas foram recebidas.
  • O resultado então diz quantas versões o projeto usa que não estão neste computador, e por quê. Por exemplo, ele diz Você cancelou o download das versões que este projeto usa. Ou informa uma versão que o Door43 não tem: O Door43 não tem es-419_tw v37, que este projeto usa. Se uma versão não puder ser obtida, o tC4 ainda baixa as outras.
  • Clique em Baixar no resultado para obtê-las agora, ou sincronize de novo mais tarde. A próxima sincronização baixa o que ainda estiver faltando.
  • Se a internet for desligada durante o download, o download para e o resultado avisa.

Conflitos de quadros de histórias

Em projetos de Open Bible Stories, a sincronização pode encontrar quadros que dois colegas alteraram.

  • O aviso da sincronização diz 1 conflito de quadro para revisar (ou o número de conflitos), com um link Revisar.
  • O cartão da história no Início e a barra superior de Traduzir mostram uma etiqueta âmbar 1 conflito · Revisar.

Formato do projeto e arquivos reparados

  • Se o translationCore mais novo de um colega salvou o projeto em um formato no qual esta versão não consegue salvar, a sincronização para e o aviso informa o formato dele (por exemplo 1.4 ou 2).
  • Se format.json foi excluído ou danificado no Door43, o tC4 coloca de volta a cópia deste computador e o aviso acrescenta: Um arquivo do projeto foi excluído ou danificado no Door43, então o tC4 colocou sua cópia de volta.

Bom saber

  • Projetos de Bíblia e de Open Bible Stories abrem e sincronizam da mesma forma.
  • Não copie pastas de projeto entre computadores manualmente. O tC4 se recusa a abri-las, para proteger o projeto.
