Справка › Проекты Библии

Создать проект Библии

Начните новый проект перевода Библии: пустой, из файлов USFM или из Scripture Burrito. Книги вы добавите сразу после этого.

«Далее вы добавите книги. Всё здесь можно изменить позже».

Шаги

  1. На главном экране нажмите + Добавить проект, затем Новая Библия (1).
  1. «Новая Библия» спрашивает: С чего вы хотите начать? Выберите Пустой (1), Из файлов USFM (2) или Из Scripture Burrito (3).

Начать пустую Библию

  1. Нажмите Пустой.
  2. Введите Название Библии, например Kanuri Bible.
  3. Введите Название языка. Когда в списке появится подходящий язык, выберите его, чтобы поле Код заполнилось (например, French (fr) → fr). Код можно ввести и самостоятельно.
  4. Выберите Слева направо или Справа налево.
  5. Оставьте Язык проверки английским. Он входит в приложение, поэтому ничего скачивать не нужно.
  1. Нажмите Создать Библию →. Откроется окно Добавить книгу. Продолжите по разделу Добавить книгу.

Начать с файлов USFM

Используйте этот вариант, если ваш перевод уже есть в файлах USFM, по одной книге в файле. Каждый файл становится книгой нового проекта, а текст файла — её черновиком.

  1. Нажмите Из файлов USFM.
  2. Перетащите файлы на область Перетащите файлы USFM сюда или выберите файлы или нажмите на неё, чтобы выбрать их. Для каждого файла появится строка. Зелёная точка показывает, какую книгу он добавляет, например Добавляет: Тит.
  3. Оранжевая точка означает, что файл нельзя использовать, и в строке сказано почему и в какой строке файла (1). Уберите этот файл с помощью его ✕, исправьте его и добавьте снова.
  1. Когда каждая строка стала книгой, нажмите Далее →.
  2. Заполните название Библии, язык, код и направление, как для пустой Библии. Под формой Книги из ваших файлов перечисляет книги (1), а примечание показывает, какой схеме Версификация соответствует количество стихов в книгах (2). В большинстве проектов её оставляют.
  1. Нажмите Создать Библию →. Проект создаётся сразу со всеми книгами, а затем открывается Добавить книгу — на случай, если вы хотите добавить ещё.

Начать с Scripture Burrito

Используйте этот вариант для перевода Библии, который другая программа сохранила как Scripture Burrito .zip.

  1. Нажмите Из Scripture Burrito, затем перетащите .zip на область Перетащите Scripture Burrito сюда или выберите файл или нажмите на неё, чтобы выбрать файл.
  2. Форма заполняется данными из Burrito: название, язык и код. При необходимости измените их. Книги из Scripture Burrito перечисляет его книги (1). Если у Burrito есть собственная версификация, она сохраняется, и форма сообщает: Собственная версификация Scripture Burrito сохраняется.
  1. Нажмите Создать Библию →. Книги и все остальные файлы Burrito попадут в новый проект, и откроется Добавить книгу.

Чтобы отменить на любом шаге, нажмите Отмена, ← Назад или ✕. Ничего не сохраняется.

Полезно знать

  • В названии должна быть хотя бы одна обычная буква или цифра, потому что по нему называется и папка проекта. Если проект с таким названием уже есть на этом компьютере, кнопка Создать Библию → остаётся неактивной, пока вы не выберете другое название.
  • Шрифт текста задаёт шрифт, которым показывается ваш перевод. Версификация — это схема нумерации стихов; в большинстве проектов оставляют вариант по умолчанию.
  • Если код языка не принимается, попробуйте код вашего конкретного языка, например knc для центрального канури вместо kau.
  • Каждый файл USFM должен содержать одну книгу и начинаться со строки \id. Два файла одной и той же книги не принимаются, и в строке указывается эта книга.
  • Burrito, в котором не перевод Библии, а что-то другое, например Open Bible Stories, не принимается, и сообщение говорит, что в нём находится. Burrito, экспортированный из tC4, — это работа для проекта: tC4 предложит открыть его через Получить работу из файла.
  • Нажав на поле, подождите немного, прежде чем печатать, а потом проверьте название. Первые буквы могут потеряться.
  • Направление текста и шрифт можно изменить позже в разделе Настройки проекта. Название и язык пока изменить нельзя.
