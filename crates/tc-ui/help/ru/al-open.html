Справка › Выровнять

Открыть инструмент «Выровнять»

Выравнивание связывает каждое слово вашего перевода со словом языка оригинала, которое оно переводит. Откройте его из режима «Проверить».

Инструменты проверки используют эти связи, чтобы выделять ваши слова, а экспорт USFM с выравниванием сохраняет их.

Как открыть выравнивание

  1. Нажмите Проверить, затем Начать проверку → на карточке Выровнять.
  2. Выберите стих в списке стихов слева. Стихи, для которых ещё нет черновика, показаны серым.
  3. Свяжите свои слова с карточками слов. См. Свяжите свои слова с источником.
  4. Когда стих готов, нажмите ✓ Отметить как действительное. См. Отметить выравнивание как завершённое.

Чтобы выйти, нажмите ← Все инструменты проверки вверху слева или ← Назад к переводу внизу слева.

На этом экране

  • Язык-мост · ULT выравнивает по понятному вам тексту языка-моста. Его слова уже связаны с языком оригинала. Оригинал · греческий выравнивает прямо по греческим словам. См. Выравнивание по тексту на языке-мосте или по языку оригинала.
  • Параметр Предлагать связи сначала выключен. Включите его, чтобы получать предложения связей на основе уже выровненных вами стихов. См. Подсказки для выравнивания.
  • Над банком слов счётчик показывает, сколько слов стиха уже размещено.
  • Как работает выравнивание открывает краткое объяснение.

Примечание: выравнивание предназначено для книг Библии. В проектах историй карточки «Выровнять» нет.

Стихи, импортированные с выравниванием

Если книга пришла из файла USFM, в котором уже было выравнивание, её выровненные стихи открываются в инструменте выравнивания с сообщением В этом стихе уже есть выравнивание. Пока что эти стихи нельзя изменить в инструменте выравнивания. tC4 сохраняет их выравнивание таким, каким оно было импортировано, и без изменений записывает его в экспорт USFM с выравниванием.

Полезно знать

  • Исходные карточки всегда следуют тексту на языке оригинала, который использует ваш проект. Если сохранённая связь указывает на слово, которого в этом тексте нет, связь удаляется, её слова возвращаются в банк слов, а стих помечается для просмотра.
