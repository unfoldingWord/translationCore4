alpha.1 — First public build

The first public snapshot of translationCore 4, a ground-up rewrite. Create a project and draft beside source texts.

What arrived

  • Draft: create a project, choose source texts, and draft beside them. See Start a new Bible project.
  • Check and Align: work started, entering review.
  • Format: every project is a Scripture Burrito.

Worth knowing

  • translationCore 3 is a separate program. Projects can now be imported (see Import a project), but tC3 versions do not carry over.
