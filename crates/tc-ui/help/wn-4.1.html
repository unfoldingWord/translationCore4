What's new in 4.1

Helps cards grouped by verse with named Translation Academy links and word intros, Clear alignments on Align, story frame conflicts on sync, project-format sync guards, and an app language that follows the computer until you choose.

translationCore 4.1 builds on the 4.0 rc.2 public beta. These are the main changes translators see.

Start a Bible from files

  • New Bible first asks How do you want to start?: Blank, From USFM files or From a Scripture Burrito.
  • From USFM files, each file is checked first and its row says which book it adds, or why it can't be used. The form then suggests the versification the books fit.
  • From a Scripture Burrito, the form fills in from the Burrito and lists its books.

See Create a Bible project.

Drafting boxes

  • The section editor in Translate and the frame editor for stories are as tall as the source beside them. Longer text scrolls inside the box; drag its corner to make it taller.
  • Highlights for a note or word now land on the right words where the gateway text joins two verses into one (a verse span).

See Draft a section and Translate a story.

About and other changes

  • About translationCore shows the version number, the translationCore® trademark statement on the copyright line, and Third-party licenses.
  • Menus and buttons in Hindi use a Devanagari font.
  • File pickers open in the folder you used last.

Helps

  • Notes are grouped under verse headings. Cards sit under uppercase headings such as INTRODUCTION and VERSE 1. The old NOTE / KEY WORD badges and verse pills are gone.
  • Article links use the real name. A note that opens Translation Academy now says Abstract Nouns → (or the article's own title), not a generic Translation Academy →.
  • Word cards show the first paragraph of the Translation Words article, then Read the article →.
  • Click a word card to highlight every occurrence of that word across the section.
  • Articles render cleanly — line breaks, superscripts and underlines from the source no longer show as raw tags. A floating close control sits above a divider.

See The helps panel in Translate, Translation notes and Word links.

Align

  • Clear alignments sits on the same footer row as ✓ Mark valid. It asks first, then sends every placed word on that verse back to the word bank. Cards keep their original words.

See Mark an alignment done.

Team sync and stories

  • Story frame conflicts. When two teammates both change a frame, sync reports 1 frame conflict to review, and Home and Translate show an amber 1 conflict · Review chip.
  • Newer project format. If a teammate's newer translationCore saved the project in a format this version cannot save to, sync stops and names their format.
  • Repaired Door43 files. If format.json was deleted or damaged on Door43, tC4 puts this computer's copy back and tells you.

See Working as a team on several computers and Find a story on Home.

Language

  • App language follows the computer until you choose one in App language. After you pick, tC4 keeps your choice.
  • Change checking language no longer offers the language already in use, and the confirm actions sit side by side.

See Change the app language and Change the checking language.

Added after 4.1.0-preview2

These changes came after the 4.1.0-preview2 test build. They are part of 4.1.

  • Check: the source cards add the simplified text (UST, or GST such as the Indonesian one) beside the original and the literal text. See Check with Translation Notes.
  • Check: only a mark saves the words you selected. Changing the words takes the mark away, Previous and Next wait until you mark or unselect, and leaving asks Stay or Leave without them. See Decide on a check item.
  • Helps: the helps stay on the section, verse or story frame you clicked, also after Save. See The helps panel in Translate.
  • Open a project from Door43: tC4 downloads the versions the project uses that your computer lacks, names each one, and Cancel stops the open cleanly. If a version can't be had, no project is added. See Working as a team on several computers.
  • Sync with Door43: after the sync, tC4 downloads the versions the project uses that this computer lacks, with a line, a bar and Cancel download on the project card. A cancelled or failed download leaves the sync done, and the result says which versions are still missing and why. See Versions the project uses.
  • Get source texts: a download keeps its line and Cancel until it ends; upgrades and their confirmations belong to the project where you started them. See Download source texts.
  • Community Checking: with drop caps, verse 1 shows no small number beside the large chapter number. See Community Checking.
  • Installers: a newer build replaces the installed translationCore 4 on macOS (it asks first) and Windows, keeping projects and settings. See Install and start tC4.
