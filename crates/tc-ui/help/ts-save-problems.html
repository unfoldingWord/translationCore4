When a save fails

If a save fails, your text stays on screen. Click Retry, and don’t close tC4 until it says Saved.

The indicator at the top right shows Saved, Saving…, Unsaved changes or Save failed — retry.

Steps

  1. If you see Save failed — retry, click Retry once and wait.
  1. If it fails again, stay on the screen. Moving to another mode may be refused until the save works.
  2. If you try to close tC4 with unsaved changes, it warns you. Stay, and try Retry again.
  3. If it keeps failing, write down the message and ask for help.

Good to know

  • Clicking Retry many times doesn't help. It tries once at a time.
  • In an imported project, writing the first text into an empty verse can fail to save every time. Retry won't fix it. Copy your text somewhere safe before you close tC4, because the verse comes back empty. Cancelling such a verse after typing can show the same message.
  • ← All checking tools still works while a save problem is showing.
  • If the message under the save indicator says This project was synced, so the app must open it again, click Home, open the project again, and make your last change again. Retry won't help in that case. See Messages that protect your project.
