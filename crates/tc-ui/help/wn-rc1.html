What's new in 4.0 rc.1

Get your work out and bring existing work in: export a book as PDF, USFM or a Scripture Burrito, export stories as Markdown, PDF or a burrito, and import translationCore 3, USFM and Scripture Burrito files. Plus project Settings on the Home card, new books opening in Understand, English helps v91 in the box, and Spacing and Paper size for printing.

What arrived

Export

All exports start from Check › Community Checking › Open → › Export. When the file is saved, the panel says "Saved <file name>".

  • Bible book: Export PDF, USFM, aligned, USFM, plain and Scripture Burrito (.zip). See Export a book as PDF, Export a book as USFM and Export a project as a Scripture Burrito.
  • Open Bible Stories: Export PDF (with or without pictures), Story Markdown (.zip) and Scripture Burrito (.zip). See Export stories as PDF or Markdown.
  • A book with nothing drafted isn't printed. tC4 tells you to draft at least one verse first.

Import

+ Add a project › Import a project makes a new project from a translationCore 3 project, USFM files or a Scripture Burrito. See Import a project.

  • The review shows the books, three checks (License, Details, Missing verses) and what carries over.
  • A missing language code or a Bible name already in use must be fixed before you can import.
  • Damaged files are refused with a reason and a code, and nothing is created. See Messages that protect your project.
  • The new card has an Imported badge.

Also new

  • Settings on the card: click Settings on a project's Home card. See Project settings.
  • A cleaner top bar. Cards say "Only on this computer" or where the project is shared. See The Home screen.
  • New books open in Understand, so you read before you draft. After that a book reopens in the mode you used last. See The three modes.
  • English helps v91 come with the app, so a new project needs no download. See What comes with the app.
  • Moving between a Bible and a stories project no longer confuses their notes and words. See Check a story.
  • Page setup for printing: spacing and paper size for Bible books, and picture layout for stories. See Community Checking preview and Story preview and export.
  • Window › Reload (Ctrl+R) brings the app back without quitting. A screen that can't be drawn shows "This screen could not be shown." with Back to Home. See If the app closed unexpectedly.
  • Resume returns to the last mode, including the checking tool you were using. See Resume where you left off.
  • Check for updates offers only the texts your books need. A New Testament project isn't offered the Hebrew text. See Update scripture texts.
  • Changing the checking language keeps the checks that still match. The rest come back as work; nothing is deleted. See Change the checking language.
  • translationCore 3 imports ask whether to look up the resource versions on Door43 or use the ones on this computer. See Import a project.

Worth knowing

  • After you join verses into a span, the book's percentage can drop, and the Resume banner can still name the old verse.
  • The "… was imported" message doesn't close by itself. Close it with its ✕.
  • In USFM exports, the \h, \toc and \mt lines carry the book code (for example TIT), not the book name.
  • On Linux, the save window's Save and Cancel buttons can be off-screen. Press Enter to save, or Esc to cancel.
  • The same language can be named two ways, for example "Español (Latinoamérica)" in lists and "Spanish (Latin American)" in sentences.
