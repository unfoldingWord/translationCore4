Travailler en équipe sur plusieurs ordinateurs

Partagez un projet sur Door43 ; chaque coéquipier l’ouvre ensuite depuis Door43 et utilise Synchroniser avec Door43 pour échanger le travail.

Une fois qu’un projet biblique ou Open Bible Stories est sur Door43, chaque coéquipier peut travailler sur son propre ordinateur et échanger les modifications avec Synchroniser avec Door43.

Commencer à partager (propriétaire du projet)

  1. Sur l’écran d’accueil, sélectionnez Partager sur Door43 sur la carte du projet et suivez les étapes. Voir Partager sur Door43.
  2. Sur Door43, donnez à chaque coéquipier un accès en écriture au dépôt. Sans cela, les coéquipiers ne peuvent pas synchroniser.
  3. La carte indique maintenant Sur Door43 et Partagé sur le dépôt, et son bouton devient Synchroniser avec Door43.

Rejoindre un projet (coéquipier)

  1. Sélectionnez + Ajouter un projet, puis Ouvrir un projet depuis Door43.
  2. Tapez owner/repository, ou collez le lien vers le dépôt, puis cliquez sur Ouvrir le projet. Un dépôt privé s’ouvre une fois que vous êtes connecté à Door43.
  3. Si Internet est désactivé, tC4 demande d’abord. Cliquez sur Activer Internet ; Pas maintenant ne récupère rien.

Le projet garde le nom que l’équipe lui a donné ; tC4 n’en demande pas. tC4 vérifie chaque fichier avant d’ajouter le projet.

Un projet utilise des versions précises de ses textes sources et de ses aides. Si certaines ne sont pas sur votre ordinateur, tC4 les télécharge d’abord, et la boîte de dialogue nomme chacune d’elles, par exemple Téléchargement de en_tn v91, que ce projet utilise. Versions restantes après celle-ci : 8. Une barre en dessous montre l’avancement de cette version. Cliquez sur Annuler pour arrêter : la boîte de dialogue indique L’ouverture a été annulée. Aucun projet n’a été ajouté à cet ordinateur.

  • Si le projet est déjà sur cet ordinateur, la boîte de dialogue indique Vous avez déjà ce projet sur cet ordinateur. Un projet a une seule copie sur chaque ordinateur. Cliquez sur Ouvrir le vôtre.
  • Si Door43 n’a pas une version utilisée par le projet, ou si elle ne peut pas être téléchargée, la boîte de dialogue indique Ce projet ne peut pas être ouvert. et nomme la version, par exemple Door43 n’a pas en_ult v91, que ce projet utilise. Aucun projet n’est ajouté. Cliquez sur Demander de l’aide si cela se reproduit.

Synchroniser

Sélectionnez Synchroniser avec Door43 sur la carte du projet. Le résultat indique combien de modifications viennent des coéquipiers et combien de conflits ont gardé la version la plus récente. Si un coéquipier a aligné le même verset après vous, le résultat le nomme, par exemple Tite 1:1 : l’alignement de Ana a remplacé le vôtre. Vos liens pour ce verset retournent dans la banque de mots. Ouvrez le verset dans Aligner pour le vérifier. Rien n’est fusionné automatiquement.

Si Internet est désactivé, tC4 demande d’abord. Pas maintenant n’envoie rien. Si vous n’êtes pas connecté, tC4 vous demande de vous connecter à Door43.

Les versions utilisées par le projet

Un coéquipier a peut-être fait passer le projet à une version plus récente d’un texte source ou d’une aide, ou cet ordinateur n’a peut-être pas l’une des versions utilisées par le projet. Une fois la synchronisation terminée, tC4 télécharge chaque version qui manque sur cet ordinateur, sans poser de question. Pendant le téléchargement, la carte du projet indique par exemple Téléchargement de es-419_twl v18, que ce projet utilise. Versions restantes après celle-ci : 4. Une barre et Annuler le téléchargement se trouvent à côté.

  • La synchronisation compte même si vous annulez le téléchargement ou si une version ne peut pas être téléchargée. Vos modifications ont été envoyées, et celles de vos coéquipiers ont été reçues.
  • Le résultat indique ensuite combien de versions utilisées par le projet ne sont pas sur cet ordinateur, et pourquoi. Par exemple, il indique Vous avez annulé le téléchargement des versions que ce projet utilise. Ou il nomme une version que Door43 n’a pas : Door43 n’a pas es-419_tw v37, que ce projet utilise. Si une version ne peut pas être obtenue, tC4 télécharge quand même les autres.
  • Cliquez sur Télécharger dans le résultat pour les obtenir maintenant, ou synchronisez de nouveau plus tard. La synchronisation suivante télécharge ce qui manque encore.
  • Si Internet est désactivé pendant le téléchargement, le téléchargement s’arrête et le résultat l’indique.

Conflits de cadres d’histoires

Dans les projets Open Bible Stories, la synchronisation peut trouver des cadres que deux coéquipiers ont tous les deux modifiés.

  • La notification de synchronisation affiche 1 conflit de cadre à examiner (ou le nombre) avec un lien Examiner.
  • La carte des histoires sur l’accueil et la barre du haut de Traduire affichent une pastille orange 1 conflit · Examiner.

Format du projet et fichiers réparés

  • Si la version plus récente de translationCore d’un coéquipier a enregistré le projet dans un format que cette version ne peut pas enregistrer, la synchronisation s’arrête et la notification nomme ce format (par exemple 1.4 ou 2).
  • Si format.json a été supprimé ou endommagé sur Door43, tC4 remet la copie de cet ordinateur et la notification ajoute : Un fichier du projet a été supprimé ou endommagé sur Door43, alors tC4 a remis votre copie.

Bon à savoir

  • Les projets bibliques et Open Bible Stories s’ouvrent et se synchronisent de la même façon.
  • Ne copiez pas à la main des dossiers de projet d’un ordinateur à un autre. tC4 refuse de les ouvrir, pour protéger le projet.
