Installer et lancer tC4

Téléchargez translationCore 4 pour votre ordinateur, installez-le ou décompressez-le, puis lancez-le. Il s’ouvre sur l’écran d’accueil.

Le téléchargement contient déjà les textes sources, les aides à la traduction et les images des histoires : vous pouvez donc commencer sans Internet.

Étapes

  1. Prenez le fichier pour votre ordinateur sur la page des versions de tC4 : le .exe pour Windows, le .pkg pour macOS (puce Apple), ou le .zip pour Linux.
  2. Installez-le :
    • Windows : lancez le .exe. Si Windows vous avertit au sujet d’une application inconnue, choisissez Informations complémentaires, puis Exécuter quand même. Lancez tC4 depuis le menu Démarrer.
    • macOS : ouvrez le .pkg. Si macOS le bloque, ouvrez Réglages Système › Confidentialité et sécurité et choisissez Ouvrir quand même. Lancez ensuite translationCore 4 depuis Applications.
    • Linux : décompressez le zip, ouvrez un terminal dans le dossier translationCore4 et lancez ./start-tc4.sh.
  3. La première fois, une petite fenêtre affiche « Préparation de translationCore4 » et compte les ressources, par exemple « Préparation des ressources : 2 sur 16 ». Attendez la fin. Cela peut prendre une minute sur un ordinateur lent. Les lancements suivants sont rapides ; la fenêtre ne s’affiche qu’un instant.
  1. tC4 s’ouvre sur l’accueil avec le titre Vos projets.
  1. Cliquez sur + Ajouter un projet pour commencer votre premier projet. Voir L’écran d’accueil.

Les avertissements de l’étape 2 apparaissent parce que les programmes d’installation ne sont pas encore signés. Ils n’apparaissent que la première fois.

Bon à savoir

  • Installer une version plus récente : installez-la par-dessus celle que vous avez ; inutile de supprimer l’ancienne d’abord. Vos projets et vos paramètres restent où ils sont.
    • Sur macOS, si translationCore 4 est déjà sur le Mac, le programme d’installation liste les copies trouvées et demande Replace it with this version? Your projects and settings stay where they are. (« La remplacer par cette version ? Vos projets et vos paramètres restent où ils sont. »). Cliquez sur Replace (Remplacer). Cancel (Annuler), ou aucune réponse pendant 5 minutes, n’installe rien, et le programme d’installation indique alors que l’installation a échoué. Si une ancienne copie ne peut pas être supprimée, le programme d’installation la nomme pour que vous puissiez la mettre à la Corbeille. La bêta 4.0 de tC4 (translationCore4) est une autre application et reste en place.
    • Sur Windows, le programme d’installation s’installe par-dessus l’ancienne version dans le même dossier et supprime d’abord les fichiers de programme de l’ancienne version.
  • La barre de menus de la fenêtre contient Edit, View et Window. Window › Reload recharge l’écran.

Si l’application ne démarre pas

  • Windows affiche « The backend could not be started » : installez Microsoft Visual C++ Redistributable (x64), puis relancez tC4.
  • Rien de nouveau ne s’ouvre : une seule copie de tC4 peut fonctionner à la fois. Le relancer fait réapparaître la fenêtre déjà ouverte.
  • « translationCore4 could not start … Bundled archive checksum mismatch » : le téléchargement est endommagé. Cliquez sur OK, téléchargez-le de nouveau et lancez la nouvelle copie.
  • Vous avez fermé tC4 pendant la préparation : relancez-le. Il reprend et fait le ménage.
  • Linux affiche une ligne au sujet de « --no-sandbox » : c’est normal pour le zip.

tC4 est encore une préversion. Gardez une copie de votre travail important ailleurs.
