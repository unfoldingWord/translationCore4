Créer un projet biblique

Commencez un nouveau projet de traduction de la Bible : vierge, à partir de fichiers USFM ou à partir d’un Scripture Burrito. Vous ajoutez les livres juste après.

« Vous ajouterez les livres ensuite. Tout ceci peut être changé plus tard. »

Étapes

  1. Sur l’accueil, cliquez sur + Ajouter un projet, puis sur Nouvelle Bible (1).
  1. Nouvelle Bible demande Comment voulez-vous commencer ? Choisissez Vierge (1), À partir de fichiers USFM (2) ou À partir d’un Scripture Burrito (3).

Commencer une Bible vierge

  1. Cliquez sur Vierge.
  2. Tapez un Nom de la Bible, par exemple Kanuri Bible.
  3. Tapez le Nom de la langue. Quand une langue correspondante apparaît dans la liste, choisissez-la pour que le Code se remplisse (par exemple French (fr) → fr). Vous pouvez aussi taper le code vous-même.
  4. Choisissez De gauche à droite ou De droite à gauche.
  5. Laissez la Langue de vérification sur l’anglais. Elle est fournie avec l’application : vous n’avez rien à télécharger.
  1. Cliquez sur Créer la Bible →. La fenêtre Ajouter un livre s’ouvre. Continuez avec Ajouter un livre.

Commencer à partir de fichiers USFM

Choisissez cette option quand votre traduction est déjà dans des fichiers USFM, un livre par fichier. Chaque fichier devient un livre du nouveau projet, avec le texte du fichier comme brouillon.

  1. Cliquez sur À partir de fichiers USFM.
  2. Déposez vos fichiers sur Déposez vos fichiers USFM ici, ou parcourez, ou cliquez dessus pour les choisir. Chaque fichier a sa ligne. Un point vert indique le livre qu’il ajoute, par exemple Ajoute Tite.
  3. Un point orange signifie que le fichier ne peut pas être utilisé ; la ligne dit pourquoi et à quelle ligne du fichier (1). Retirez ce fichier avec son ✕, corrigez-le, puis ajoutez-le de nouveau.
  1. Quand chaque ligne correspond à un livre, cliquez sur Suivant →.
  2. Remplissez le nom de la Bible, la langue, le code et le sens comme pour une Bible vierge. Sous le formulaire, Livres de vos fichiers liste les livres (1), et une remarque indique à quelle Versification correspond le nombre de versets des livres (2). La plupart des projets la gardent.
  1. Cliquez sur Créer la Bible →. Le projet est créé avec tous ses livres en une seule étape, et Ajouter un livre s’ouvre au cas où vous en voudriez d’autres.

Commencer à partir d’un Scripture Burrito

Choisissez cette option pour une traduction de la Bible qu’un autre outil a enregistrée sous forme de Scripture Burrito .zip.

  1. Cliquez sur À partir d’un Scripture Burrito, puis déposez le .zip sur Déposez votre Scripture Burrito ici, ou parcourez, ou cliquez dessus pour le choisir.
  2. Le formulaire se remplit à partir du Burrito : le nom, la langue et le code. Changez-les si besoin. Livres du Scripture Burrito liste ses livres (1). Un Burrito qui a sa propre versification la garde, et le formulaire indique La versification propre au Scripture Burrito est conservée.
  1. Cliquez sur Créer la Bible →. Les livres et tous les autres fichiers du Burrito entrent dans le nouveau projet, et Ajouter un livre s’ouvre.

Pour annuler à n’importe quelle étape, cliquez sur Annuler, ← Retour ou le ✕. Rien n’est enregistré.

Bon à savoir

  • Le nom doit contenir au moins une lettre simple ou un chiffre, car il sert aussi à nommer le dossier du projet. Si un projet de ce nom est déjà sur cet ordinateur, Créer la Bible → reste désactivé jusqu’à ce que vous choisissiez un autre nom.
  • Police du texte définit la police dans laquelle votre traduction s’affiche. Versification est le système de numérotation des versets ; la plupart des projets gardent celui par défaut.
  • Si un code de langue est refusé, essayez le code de votre langue précise, par exemple knc pour le kanouri central plutôt que kau.
  • Chaque fichier USFM doit contenir un seul livre et commencer par une ligne \id. Deux fichiers du même livre sont refusés, et la ligne nomme le livre.
  • Un Burrito qui contient autre chose qu’une traduction de la Bible, par exemple des Open Bible Stories, est refusé, et tC4 indique ce qu’il contient. Un Burrito exporté depuis tC4 est du travail pour un projet : tC4 vous demande de l’ouvrir plutôt avec Recevoir du travail depuis un fichier.
  • Après avoir cliqué dans un champ, attendez un instant avant de taper, puis vérifiez le nom. Les premières lettres peuvent se perdre.
  • Vous pouvez changer le sens du texte et la police plus tard dans les Paramètres du projet. Le nom et la langue ne peuvent pas encore être changés.
