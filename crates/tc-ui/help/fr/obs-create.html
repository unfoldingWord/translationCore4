Commencer un projet Open Bible Stories

Créez un projet pour traduire les cinquante Open Bible Stories dans votre langue.

Les Open Bible Stories sont 50 courtes histoires bibliques, chacune racontée en cadres numérotés avec une image. Les histoires et les aides en anglais sont fournies avec l’application.

Étapes

  1. Sur l’accueil, cliquez sur + Ajouter un projet, puis sur Nouvelles Open Bible Stories.
  2. Tapez un Nom du projet, le Nom de la langue et son Code.
  3. Choisissez le Sens du texte. Laissez Langue de vérification sur l’anglais.
  1. Cliquez sur Créer les histoires →. La nouvelle carte apparaît sur l’accueil.
  2. Cliquez sur la vignette d’une histoire (1) pour l’ouvrir. Une nouvelle histoire s’ouvre dans Comprendre.

Pour annuler, cliquez sur Annuler ou sur le ✕. Rien n’est enregistré.

Bon à savoir

  • Après avoir cliqué dans un champ, attendez un instant avant de taper, puis vérifiez ce que vous avez tapé. Les premières lettres peuvent être perdues.
  • Vous pourrez changer plus tard le sens du texte, la police et la langue de vérification dans les Paramètres du projet. Le nom et la langue ne peuvent pas encore être changés.
