Membuat proyek Alkitab

Mulai proyek penerjemahan Alkitab baru: kosong, dari file USFM, atau dari Scripture Burrito. Anda menambahkan kitab sesudahnya.

"Anda akan menambahkan kitab berikutnya. Semua hal di sini dapat diubah nanti."

Langkah-langkah

  1. Di Beranda, klik + Tambah proyek, lalu Alkitab Baru (1).
  1. Alkitab Baru bertanya Bagaimana Anda ingin memulai? Pilih Kosong (1), Dari berkas USFM (2), atau Dari Scripture Burrito (3).

Memulai Alkitab kosong

  1. Klik Kosong.
  2. Ketik Nama Alkitab, misalnya Kanuri Bible.
  3. Ketik Nama bahasa. Saat bahasa yang cocok muncul di daftar, pilih bahasa itu agar Kode terisi (misalnya French (fr) → fr). Anda tetap dapat mengetik kodenya sendiri.
  4. Pilih Dari kiri ke kanan atau Dari kanan ke kiri.
  5. Biarkan Bahasa pemeriksaan pada bahasa Inggris. Bahasa ini sudah disertakan dalam aplikasi, jadi Anda tidak perlu mengunduh apa pun.
  1. Klik Buat Alkitab →. Dialog Tambah kitab terbuka. Lanjutkan dengan Menambah kitab.

Memulai dari file USFM

Gunakan cara ini jika terjemahan Anda sudah ada dalam file USFM, satu kitab per file. Setiap file menjadi sebuah kitab dalam proyek baru, dengan teks file sebagai drafnya.

  1. Klik Dari berkas USFM.
  2. Lepaskan file Anda di Lepaskan file USFM Anda di sini, atau telusuri, atau klik area itu untuk memilih file. Setiap file mendapat satu baris. Titik hijau menunjukkan kitab yang ditambahkannya, misalnya Menambahkan Titus.
  3. Titik oranye berarti file itu tidak dapat dipakai, dan barisnya menjelaskan alasannya serta di baris mana (1). Hapus file itu dengan tombol ✕-nya, perbaiki, lalu tambahkan lagi.
  1. Setelah setiap baris menjadi kitab, klik Berikutnya →.
  2. Isi nama Alkitab, bahasa, kode, dan arah teks seperti untuk Alkitab kosong. Di bawah formulir, Kitab dari berkas Anda menampilkan daftar kitab (1), dan sebuah catatan menyebutkan Versifikasi yang cocok dengan jumlah ayat kitab-kitab itu (2). Sebagian besar proyek mempertahankannya.
  1. Klik Buat Alkitab →. Proyek dibuat beserta semua kitabnya dalam satu langkah, lalu Tambah kitab terbuka jika Anda ingin menambah kitab lagi.

Memulai dari Scripture Burrito

Gunakan cara ini untuk terjemahan Alkitab yang disimpan oleh alat lain sebagai .zip Scripture Burrito.

  1. Klik Dari Scripture Burrito, lalu lepaskan file .zip di Lepaskan Scripture Burrito Anda di sini, atau telusuri, atau klik area itu untuk memilihnya.
  2. Formulir terisi dari Burrito: nama, bahasa, dan kode. Ubah jika perlu. Kitab dari Scripture Burrito menampilkan daftar kitabnya (1). Burrito yang memiliki versifikasi sendiri tetap memakainya, dan formulir menampilkan Versifikasi milik Scripture Burrito ini tetap dipakai.
  1. Klik Buat Alkitab →. Kitab-kitab dan file lain dari Burrito masuk ke proyek baru, lalu Tambah kitab terbuka.

Untuk membatalkan di langkah mana pun, klik Batal, ← Kembali, atau ✕. Tidak ada yang disimpan.

Perlu diketahui

  • Nama harus memuat setidaknya satu huruf biasa atau angka, karena nama itu juga dipakai untuk folder proyek. Jika proyek dengan nama itu sudah ada di komputer ini, Buat Alkitab → tetap nonaktif sampai Anda memilih nama lain.
  • Font aksara menentukan font untuk menampilkan terjemahan Anda. Versifikasi adalah sistem penomoran ayat; sebagian besar proyek memakai pengaturan bawaan.
  • Jika kode bahasa ditolak, coba kode untuk bahasa Anda yang lebih spesifik, misalnya knc untuk Kanuri Tengah, bukan kau.
  • Setiap file USFM harus berisi satu kitab dan dimulai dengan baris \id. Dua file untuk kitab yang sama akan ditolak, dan barisnya menyebutkan nama kitab itu.
  • Burrito yang berisi sesuatu selain terjemahan Alkitab, misalnya Open Bible Stories, akan ditolak dengan keterangan isinya. Burrito yang diekspor dari tC4 adalah pekerjaan untuk sebuah proyek: tC4 meminta Anda membukanya dengan Terima pekerjaan dari berkas.
  • Tunggu sebentar setelah mengklik sebuah kolom sebelum Anda mengetik, lalu periksa namanya. Huruf-huruf pertama bisa hilang.
  • Anda dapat mengubah arah teks dan font nanti di Pengaturan proyek. Nama dan bahasa belum dapat diubah.
