Mengekspor cerita sebagai PDF atau Markdown

Simpan PDF cerita Anda yang siap cetak, zip Story Markdown, atau Scripture Burrito.

  • Ekspor PDF: salinan baca untuk peninjau, dengan atau tanpa gambar.
  • Cerita dalam Markdown (.zip): file-file cerita untuk alat Open Bible Stories lainnya.
  • Scripture Burrito (.zip): seluruh proyek. Lihat Mengekspor proyek sebagai Scripture Burrito.

Langkah-langkah

  1. Buka sebuah cerita dan klik Periksa, lalu Buka → pada Pemeriksaan Komunitas.
  2. Opsional: pilih tata letak dan gambar. Lihat Pratinjau dan ekspor cerita.
  3. Klik Ekspor (1), lalu pilih format (2).
  1. Gunakan nama file yang disarankan atau ketik nama lain, lalu simpan. Panel menampilkan "<nama file> disimpan".

Untuk membatalkan, tutup jendela simpan. Tidak ada file yang dibuat.

Perlu diketahui

  • Susun draf setidaknya judul atau satu bingkai sebelum Anda mengekspor PDF.
  • Untuk menyimpan PDF kedua dengan tata letak lain, ubah tata letaknya, ekspor lagi, dan beri nama baru.
  • Jika Anda melihat "Aplikasi tidak dapat mencetak PDF bersama gambarnya…", matikan Gambar lalu ekspor lagi.
  • Di Linux, jendela simpan terbuka di folder Downloads Anda. Jika Anda tidak dapat melihat tombolnya, tekan Enter untuk menyimpan atau Esc untuk membatalkan.
