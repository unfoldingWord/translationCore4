Pesan yang melindungi proyek Anda

Jika tC4 menemukan sesuatu yang tidak terduga, aplikasi berhenti daripada membahayakan pekerjaan Anda, lalu memberi tahu apa yang perlu dilakukan.

Setiap pesan menyebutkan apakah pekerjaan Anda sudah disimpan, atau bahwa tidak ada yang dibuat.

Langkah-langkah

  1. Baca pesannya dan ikuti sarannya.
  1. Untuk file impor yang ditolak, klik ← Pilih file lain untuk memilih file yang baik, atau Batal.
  2. Jika pesan bertuliskan "Minta bantuan", hubungi orang yang mendukung Anda dan biarkan folder proyek apa adanya.

Pesan saat Anda mengimpor

KodeContohYang perlu dilakukan
import.damaged.truncated"… bukan file zip yang lengkap."File zip terpotong. Ekspor atau salin lagi.
import.damaged.no-manifest"… tidak memiliki manifest.json, jadi ini bukan proyek translationCore 3."Pilih file zip yang diekspor oleh translationCore 3.
import.damaged.corrupt-entry"… rusak … sehingga tidak dapat dibaca."Ekspor lagi dari translationCore 3.
import.name-exists"Proyek dengan nama ini sudah ada di komputer ini."Ketik nama Alkitab yang lain.
import.write-failed"Alkitab yang baru ditulis sebagian telah dihapus…"Coba lagi. Jika terjadi lagi, minta bantuan.

File USFM diperiksa sebelum apa pun dibuat, di Alkitab Baru › Dari berkas USFM dan di Tambah kitab › Tambah kitab dari file USFM. File yang tidak dapat dipakai mendapat titik oranye dan menyebutkan alasannya serta di baris mana, misalnya "GEN-draft.usfm tidak dapat ditambahkan: baris 4: pasal 1 muncul dua kali." Hapus file itu dengan ✕ miliknya, perbaiki file, lalu tambahkan lagi.

Pesan saat Anda membuka, menyimpan, atau mengekspor

Pesan diawali denganYang perlu dilakukan
"Sebuah file diubah di luar aplikasi."Buka proyek lagi. tC4 memperbaiki apa yang bisa diperbaiki dan menyebutkan apa yang tidak bisa.
"File cerita diubah di luar aplikasi."Batalkan perubahan dari luar itu, lalu buka proyek lagi.
"Folder perubahan komputer ini memuat perubahan komputer lain."Folder proyek disalin secara manual. Minta bantuan.
"… belum memiliki ayat yang didraf, sehingga PDF tidak memiliki apa pun untuk dicetak."Susun draf setidaknya satu ayat, lalu ekspor lagi.
"Aplikasi tidak dapat mencetak PDF…"Tutup tC4, buka lagi, lalu ekspor lagi. Untuk cerita, coba dengan Gambar dimatikan.
"Proyek ini telah disinkronkan, jadi aplikasi harus membukanya lagi."Sinkronisasi mengubah proyek saat proyek sedang terbuka. Klik Beranda, buka proyek lagi, lalu buat lagi perubahan terakhir Anda. Satu klik pada Beranda menutup proyek dan membawa Anda kembali ke Beranda, meskipun penyimpanan itu belum selesai.
"Aplikasi berhenti untuk melindungi proyek Anda."Minta bantuan.
"Versi pra-rilis translationCore menyematkan tautan Kata-kata Terjemahan proyek ini…"Buat proyek lagi di versi tC4 ini. Sematan Tautan yang lama tidak dapat dipakai.

Perlu diketahui

  • Catat kodenya, atau foto pesannya, saat Anda meminta bantuan.
  • Di bawah kotak merah, pemeriksaan masih bisa tampak hijau. Percayalah pada kotak merah: file itu tidak dapat diimpor.
