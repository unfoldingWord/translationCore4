# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Use one of these private channels:

1. **GitHub private vulnerability reporting** — on this repository, open the
   **Security** tab and select **Report a vulnerability**.
2. **Email** — send the report to <birch.champeon@unfoldingword.org>.

Include: the affected file or endpoint, the steps to reproduce, and the effect you
observed. Do not publish exploit details before a fix is released.

## What to expect

- We acknowledge a report within 7 days.
- We coordinate the fix and the disclosure with you.

## Scope

This repository holds the translationCore 4 client. Reports about the Pankosmia
platform itself go to the project owner through the channels above — do not open
issues on upstream repositories (see `CONTRIBUTING.md`, hard rule 1).
