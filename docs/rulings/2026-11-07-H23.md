# H23: New Bible from a Burrito: a changed field remakes its record whole

- Asked: 2026-11-07, by the #845 session, after review of #954 found that a Create that changed
  nothing dropped what the fields cannot show (P9), and after #950 had needed a review round
  for a piece-by-piece patch of the Burrito's languages record.
- Options: keep each record as the Burrito wrote it unless the translator changed its field,
  and then remake that record whole from the fields, as for USFM files (recommended); or let
  the fields always decide the name and language, an exception to P9 even when nothing changed.
- Answer: the owner, in the #845 session on 2026-11-07: "Keep unless edited". Before that, the
  owner had said changing the language or its code when a project starts from a Burrito is no
  different from choosing them when it starts from USFM files.

## The rule

- New Bible from a Scripture Burrito opens its fields filled from the Burrito.
- At Create, a record whose field the translator did not change is the Burrito's as written:
  the name in every locale, every language with all its properties, and every setting.
- A changed field remakes its record whole from the fields, as for USFM files: the name makes
  the project name; the language name, code or direction make the languages record (one
  language, from the fields); each also makes its own setting. A changed code drops the
  Burrito's Door43 language, which the form does not show; a Door43 code picked alone changes
  only that setting.
- Nothing inside a record is patched part by part.

## Effect for translators

A Burrito that is imported as it is keeps all of its metadata. A translator who changes the
language at the start gets the language they chose, as they would from USFM files; what the
old languages record held beyond the fields (a second language, the name in other locales) is
not carried into the new project. The Burrito file itself is not changed.

## Unblocks and changes

- An exception to P9 (STORAGE §13, every non-derived `metadata.json` field kept) for a field
  the translator changes in New Bible from a Burrito. #954 builds it
  (`crates/tc-app/src/burrito.rs`, `edited_records`).
