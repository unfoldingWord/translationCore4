## Draft release notes

This public beta is version **4.0.0-rc.2**. We invite broader testing before stable
4.0.0. Do not use it for production translation work. Test with copies of projects
and keep independent backups. The beta uses tC4's normal project store; it does not
provide a separate beta store or an automatic rollback.

### Testing focus

Test the planned 4.0.0 workflows: Bible and Open Bible Stories drafting, checking
and alignment where supported; export and import; Door43 first share and team sync
round 1; and the English, Spanish, French and Arabic interfaces. Record any limits
found in the release build before publication. The detailed workflows and their
proof are in [JOURNEYS.md](../JOURNEYS.md).

Use **Report a problem** to report a defect. Include the app version, operating
system, steps, expected result and actual result.

#### Known limitations

These limits are in this build. [VERIFIED — issue states and code on `main` at `b1d1f37`, 2026-10-20]

- **Character styles in the aligned USFM export** ([#420](https://github.com/unfoldingWord/translationCore4/issues/420)). An aligned word loses the style that wraps it: `\add Jesucristo\add*` exports as an empty `\add \add*` beside the aligned word. No text is lost.
- **Projects imported before the fix** ([#821](https://github.com/unfoldingWord/translationCore4/issues/821)). A Scripture Burrito with no `vrs.json` that was imported before this build cannot save a checkpoint: the save indicator shows "Checkpoint not saved", and export and share run the same checkpoint for that project. New imports are not affected ([#813](https://github.com/unfoldingWord/translationCore4/issues/813)).
- **Imported alignment** ([#553](https://github.com/unfoldingWord/translationCore4/issues/553)). An aligned USFM file that you import or add as a book keeps its alignment markup as it is. Align shows a notice for these verses and does not edit them. The aligned USFM export keeps them as they are.
- **Keyboard** ([#568](https://github.com/unfoldingWord/translationCore4/issues/568)). A keyboard user cannot place a word on a card, merge two cards or confirm one suggestion.
- **A link without a review flag** ([#825](https://github.com/unfoldingWord/translationCore4/issues/825)). After a Translate save, a rare tie in the move rule can drop one alignment link without a review flag. The word returns to the bank. No wrong link is kept.
- **Signing.** macOS is unsigned and not notarized. Linux is an unsigned zip.
