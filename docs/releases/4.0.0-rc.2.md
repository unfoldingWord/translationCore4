## Draft release notes

This public beta is version **4.0.0-rc.2**. We invite broader testing before stable
4.0.0. Do not use it for production translation work. Test with copies of projects
and keep independent backups. The beta uses tC4's normal project store; it does not
provide a separate beta store or an automatic rollback.

### Testing focus

Test the planned 4.0.0 workflows: Bible and Open Bible Stories drafting, checking
and alignment where supported; export and import; Door43 first share and team sync
round 1; and the English, Spanish, French and Arabic interfaces. Record any limits
found in the release build before publication. The detailed workflows and their
proof are in [JOURNEYS.md](../JOURNEYS.md).

Use **Report a problem** to report a defect. Include the app version, operating
system, steps, expected result and actual result.

### Known limitations and build evidence — required before publication

Not yet recorded for this release. Add the supported workflow limits, open known
defects, installation and signing instructions, release commit, artifact IDs and
SHA-256 checksums, CI results, post-install smoke results, clean-machine witness
and offline-run evidence. Do not publish these notes with this section incomplete.

### Before stable 4.0.0

Review beta feedback, resolve release blockers and prove the release gates on the
final build. Further beta fixes keep increasing `rc.N` versions. The stable release
uses version `4.0.0`; its date depends on those results.
