translationCore 4 for macOS (Apple silicon)

This installer is not signed by Apple, as with translationCore 4.0 rc.2. If macOS blocks it,
open System Settings, then Privacy & Security, and choose Open Anyway. The installer asks for
an administrator password and puts translationCore 4 in Applications.

If translationCore 4 is already on this Mac, the installer asks before it replaces it. Replace
puts this version in Applications and removes the older copy, wherever it is. Cancel installs
nothing; the installer then says the installation failed. translationCore 4.0 rc.2
(translationCore4) is a different app and stays.

Your projects are in the translationCore4 folder in your home folder. Removing the app, or
installing a newer one, leaves them and your settings where they are.
